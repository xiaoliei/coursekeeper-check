## 3. 覆盖的规则

- 课程稳定标识：网格无课程编号，按单元格“班级：…”到「有课表课程」表反查（9/9 命中）。
- 周次：`3-18(周)`、`4,6,…,18(周)`、`15(周)` 经 B 的 `WeekText.parse` 转位图；教师名含“周”不会误判为周次行。
- 节次：条目内 `[03-04节]` 优先于行首大节标签；跨大节课程在多个行重复出现时按“天/节次/周次/地点”去重。
- 地点：`【校区】` 行与教室行分开，只取教室。
- 学期起始日：页面不提供 → null，由用户手填，不猜。
- 作业：MYSTU（Moodle）课程概览，`div.coursebox → div.assignment.overview`；标题去掉“-截止时间 …”后缀，截止时间取 `div.info`（含“星期X”也能解析），作业 ID 取 `view.php?id=`；缺 ID 以 `externalId = null` 上交计数；课程关联首版留空。
