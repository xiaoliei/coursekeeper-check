## 两项 Activity 测试的失败闭环

首次完整设备回归复现旧问题：14 项中 12 项通过，2 项报 `No compose hierarchies`。日志确认：首次创建带截止任务后，系统启动 `GrantPermissionsActivity` 请求通知权限；此时计数断言无法取得应用的 Compose 根，后一用例也受到未关闭弹窗影响。证据见 [修复前日志节选](2026-11-17/permission-before-fix.txt)。

修复只在 `HomeIntegrationTest` 的 `BeforeClass` 中，对 API 33+ 预置 `POST_NOTIFICATIONS` 授权，且在 Activity 启动前执行。正式 App 仍按原逻辑申请权限；通知授权／拒绝由 D 的专项验收覆盖，不因本轮联调用例授权而宣称拒绝态已重测。

随后两项 Activity 定向回归通过，再运行完整 14 项设备回归通过。保留所有业务断言，没有通过删掉断言或捕获异常来“变绿”。
