## 一、B-01：学期设置不回填起始日

### 现象

已有学期的情况下，打开「学期设置」只想改周数或节次，保存后**起始日被改成当天**。教学周随之整体平移，课表、首页“今日课程/本周课程”、看板数字全部变化。

### 根因

两处叠加（`43f925e` 与修复前一致）：

1. `CourseScreen` 打开对话框时固定传 `initialStartsOn = LocalDate.now()`；
2. `CourseUiState` **没有 `startsOn` 字段**——投影层 `SemesterInfo` 其实有值，但 ViewModel 组装 UI 状态时丢掉了，表单拿不到已保存日期。

### 修复

| 位置 | 改动 |
|---|---|
| `CourseUiState` | 新增 `semesterStartsOn: LocalDate?`，由 `SemesterInfo.startsOn` 填充 |
| `CourseScreen` | 打开对话框用 `state.semesterStartsOn`；仅“还没有学期”时用 `defaultSemesterStartsOn(today)`（今天所在周的周一） |
| `SemesterDialog` | 增加 `isExisting`，标题区分「修改学期 / 设置学期」，并提示“起始日已回填，只改周数或节次不会动它” |
| `CourseViewModel` | 新增顶层纯函数 `defaultSemesterStartsOn(today)`，便于单测 |

### 行为对照

| 场景 | 修复前 | 修复后 |
|---|---|---|
| 已有学期，只改周数 | 起始日变成今天 → 周次平移 | 起始日保持原值，只改周数 |
| 已有学期，只改节次时刻 | 同上 | 起始日保持原值 |
| 首次设置学期 | 用今天（不是本周一） | 用今天所在周的周一，可改 |
| 主动修改起始日 | 正常保存 | 正常保存，周次重新映射 |

### 测试

| 用例 | 断言 |
|---|---|
| 已有学期回填保存的起始日 | `semesterStartsOn == 2026-09-07` |
| 只改周数时起始日保持不变 | 周数 20→18，`semesterStartsOn` 仍为 2026-09-07 |
| 新建学期默认起始日为今天所在周的周一 | 11-12（周四）→ 11-09；11-09 → 11-09；11-15（周日）→ 11-09 |

## 二、课表跨零点更新

### 现象

App 停留在课表页跨过 00:00 后，“今天”高亮、今日列表、当前周次不刷新，直到有数据变化（同步/编辑）或用户切页签。

### 根因

`uiState` 只由三路数据驱动：

```kotlin
combine(snapshots, selectedWeek, viewMode) { snapshot, week, mode -> build(..., now()) }
```

`now()` 只在重算时读一次，没有时间源，所以时间流逝本身不会触发重算。

### 修复

`CourseViewModel` 增加 `ticks: Flow<Unit>`（默认每 60 秒 emit 一次），`combine` 改为四路：

```kotlin
combine(snapshots, selectedWeek, viewMode, ticks) { snapshot, week, mode, _ ->
    build(snapshot, week, mode, now())
}
```

与 A 的首页网关保持相同的刷新节奏。只影响展示与“今天”的判定，**不写任何存储**，日界仍是设备本地时区 00:00。

### 测试

| 用例 | 断言 |
|---|---|
| 跨零点后今日列表按新日期刷新 | 23:59（周二）`todayDay=2`、今日 1 条；tick 后 00:01（周三）`todayDay=3`、今日 0 条，周次仍为 10 |
