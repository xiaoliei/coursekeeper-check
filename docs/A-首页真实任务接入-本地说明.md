# A 首页与公共导航接入说明

更新：2026-11-17。开发基线为 main `bbf1e47`；本次交付包含 A 的真实课程、教学周、压力摘要、同步详情及与最新学校／任务模块的接入修复。提交版本与发布状态以仓库 Git 记录为准，下文为当前功能范围，11-10／11-13 的结果仅作为历史记录。

## 本轮完成

- 首页与 D 的任务页继续共用 E 的 Room 数据及任务写入口，保留版本校验、完成、撤销、日期筛选和引导状态持久化。
- 首页六项课程字段消费 B 的 `HomeCourseProjection`：今日课程数、本周课程数、课程列表、下一节课、提示及课程可用状态。兼容 C 导入后 `semesterId = null` 的同步课程，由 B 的最新投影在补录学期后正确展示；A 不另写周次算法。
- 修复下一节课为空时的错误提示：今日上完课显示“今日课程已结束”，今天没课但本周有课显示“今天没有课程”，整周为空显示“本周暂无课程”；这些状态均可前往课表，不误导用户重新登录。
- 保留 D 已统一的常驻底栏：任务页为“＋ 新建任务”，其他页为“＋ 手动添加任务”。任务页内新建不重置当前查询；从其他页新建仍切待办并打开 D 的表单。移除旧的 `snackbarBottomInset` 参数与传参。
- 保留 C 的 `loginSheet`、顶部“学校”入口、适配器单例、登录后同步失败处理和退出登录；“导入”与“学校”两个顶部入口共存。
- 保留首次引导及顶部“导入”菜单的 Excel／粘贴课程通知回调。当前只显示功能待接入提示，没有文件读取、解析或导入写库。
- 第 4 周只读接入：教学周复用 B 的 `CourseProjector.weekOf`；首页本周进度、压力分数／等级／解释复用 F 的 `StatisticsService`，与课程共用同一快照及时刻，已有分钟 tick 会重算，不依赖 F 看板是否刷新。
- 同步异常可查看课表／作业的分别结果、最近成功时间及可读原因；部分成功但存在过期模块时可通过详情进入 C 的重登入口。没有新增真实同步请求或修改合并规则。

## 接口与责任

| 接入点 | 当前行为与维护方 |
| --- | --- |
| `taskScreen`／`onCreateTask`／`onTaskFilter` | A 负责导航与查询传递，D 负责真实任务页、表单与操作 |
| `coursesScreen` | B 提供真实课表，A 负责首页跳转与展示课程投影 |
| `statisticsScreen` | F 的真实看板已接入；首页同样消费 F 的纯计算结果，不复制压力公式 |
| `loginSheet` | C 提供真实登录与学校管理；不传时保留独立演示的占位弹层 |
| `onImportExcel`／`onPasteCourseNotice` | 可选且默认 null；未传时不展示对应入口，后续解析格式确认后再接实现 |
| `onRetryHome` | 仅重新读取本地数据，不等同于学校网络同步重试 |
| `HomeUiState.syncModules`／`hasExpiredSession` | A 展示 E 的模块级同步记录；C 登录入口可据此处理整体部分成功中的过期模块 |

真实写入仍通过 D／E 的业务接口。首页使用界面所见版本提交，撤销使用写入回执版本；不读取“最新版本”绕过冲突。日期与统计口径沿用 D／E／F 已定义的契约。

## 状态与范围

- `NoSemester`：未设学期，不把缺失配置当作 0。
- `NotInTerm`：不在教学周，不误报课程服务缺失。
- `Ready`：教学周内，没课就是实际 0；当天已结束与没有安排分开提示。
- 本地读取中／失败与同步中的离线、过期、部分成功、错误分别展示，不以假同步成功替代。
- 首页压力有可计算数据时显示分数、等级和解释，无数据时保留缺失状态；未设学期而仅有任务时说明课程负荷尚待配置。顶部周次徽标显示具体教学周／待设置学期／非教学周。
- 尚未接下拉强制刷新、首页同步失败重试和前台生命周期完整同步；这些属于 A 第 4 周的后续工作。八条规则由 F 交付，Excel／通知解析另按已确认格式实施。
