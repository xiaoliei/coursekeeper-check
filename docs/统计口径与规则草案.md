## 〇、口径归属

## 一、首页与看板共用统计口径

首页摘要与数据看板使用同一套口径，任何修改必须同步两处。

| 指标 | 口径（v0.2） | 依赖 | 空值／边界 |
|---|---|---|---|
| 今日课程 `todayLessonCount` | 今天（`dayOfWeek` = 今天 且 `weeks` 含本周）有效排课**条目**数；同一课程不同时段分别计数；跨节次同一条目按 1 计 | B CourseService | 无排课显示 0 |
| 今日节数 `todayPeriodCount` | 上述条目 `endPeriod − startPeriod + 1` 之和（压力指数“课程负荷”用） | B CourseService | 无排课显示 0 |
| 本周课程 `weekCourseCount` | 本周有任一有效排课条目的**不同课程数（门）**；同名不同课程编号算两门 | B CourseService | 无课程显示 0 |
| 本周条目 `weekEntryCount` | 本周生效排课条目总数（类型/分布图表用） | B CourseService | 0 |
| 今日截止 `dueTodayCount` | 截止日期（`dueAt` 的本地日期）为今天的任务，**包含已完成**；**不含截止待定（无 `dueAt`）** | D v1.0 | 0 |
| 今日完成 `completedTodayCount` | 当前为完成状态且 `completedAt` 在今天；取消完成即移除 | D v1.0 | 0 |
| 本周进度 `weekTaskCount` / `weekCompletedCount` / `completionRate` | 分母：`dueAt` ∈ [本周一 00:00, 下周一 00:00) 的任务，**不含截止待定**；分子：其中当前已完成的任务 | D v1.0 + E Repository | 分母为 0 显示“暂无数据”，不显示 0% |
| 压力指数 `pressureScore` / `pressureLevel` / `explanation` | 公式见第二节 | F 计算；课程负荷来自 B，任务来自 D/E | 无课程且无任务时显示“暂无数据” |
| 同步状态 | 正式枚举 IDLE／SYNCING／OFFLINE／EXPIRED／PARTIAL／ERROR；模块级只用前五项，PARTIAL 由整体汇总派生 | E | 失败不能以空结果覆盖；IDLE 且 `lastSuccessAt` 为空不得显示“同步成功” |

多页面一致性：用同一组固定记录核对首页、课表、任务页和看板；新增、完成、删除、同步更新后统计结果必须保持一致。A 首页已按任务侧口径实现投影（本周按周一至下周一开区间统计截止任务），F 统计服务接入后替换其来源。

日期归属：一律按**设备本地时区**、00:00 为日界（与 D v1.0 一致）；任务状态（待办／已完成／已逾期）由代码从 `completedAt`／`dueAt` 派生，不存储。

## 二、压力指数（权重与等级 F 已定）

> 因素与权重按本版执行；等级与演示“40·适中”一致。待全体评审无异议后随 B v1.0 一起生效。

候选因素与默认权重：

| 因素 | 默认权重 | 计算建议（v0.2） |
|---|---|---|
| 任务密度 | 40% | 本周截止任务数 ÷ 本周剩余可用天数（无任务时为 0；不含截止待定） |
| 课程负荷 | 30% | 今日节数 `todayPeriodCount` 归一化（≥ 8 节记满分） |
| 临近截止 | 20% | 48 小时内未完成的任务数归一化（≥ 3 记满分；不含截止待定） |
| 逾期任务 | 10% | 已过期未完成任务数归一化（≥ 2 记满分） |

等级：0–29 轻松；30–59 适中；60–79 偏高；80–100 很高。`explanation` 须给出原因短语（如“本周任务较集中”），不能只给数字。

> 修订说明：v0.1 写“今日有效排课条目数归一化（≥ 8 节记满分）”，条目与节混用；经 B 指出后，F 确定为**今日节数**（B v0.1 的 `todayPeriodCount`，≥ 8 节满分）。今日节数 ≠ 今日条目数：跨节次课程为 1 条条目、K 节。数字由 B 的 CourseService 提供，F 只消费。

## 三、8 条规则清单与文案模板（草案）

> 阈值与文案为草案，待全体确认后生效；规则可离线运行、相同输入得到相同结果，不调用模型。
> 与 D 通知规则并行：D 负责系统通知（截止前 24h／1h、编辑或完成或删除后取消重建），F 的规则是应用内提示与看板展示；两者用同一时间口径。时间类规则（2、3、8）不处理截止待定任务（D v1.0 六-F③）。

| # | 规则 | 触发条件（草案） | 文案模板 |
|---|---|---|---|
| 1 | 今日截止提醒 | 存在今天截止的未完成任务 | “今天有 N 项任务截止，记得完成” |
| 2 | 24 小时临期 | 存在 24 小时内截止的未完成任务 | “学习报告将于今天 23:59 截止” |
| 3 | 任务集中 | 未来 48 小时内截止任务 ≥ 3 | “未来两天有 N 项任务，建议按截止时间排序” |
| 4 | 课程负荷 | 今日节数 ≥ 6 节 | “今天有 N 节课，注意安排休息” |
| 5 | 逾期提醒 | 存在已过期未完成的任务 | “有 N 项任务已逾期，可补录或调整” |
| 6 | 进度滞后 | 本周过半且完成率 < 50% | “本周已过半，完成率 N%，有些紧张” |
| 7 | 空数据引导 | 无课程且无任务 | “暂无课程和任务，可连接学校或手动添加” |
| 8 | 连续低完成 | 近 3 天每天完成数均为 0 且存在截止任务 | “连续几天没有完成记录，需要调整安排吗？” |

## 四、StatisticsService 接口草案（W2 实现）

```kotlin
// 首页与看板共用；数据来自 B（课程）、D（任务）、E（Repository/同步状态）
data class StatisticsUi(
    val weekTaskCount: Int = 0,
    val weekCompletedCount: Int = 0,
    val completionRate: Float? = null,          // 无任务为 null，UI 显示“暂无数据”
    val typeDistribution: List<TypeSlice> = emptyList(),   // 本周任务按类型分布
    val dueDist: DueDistribution = DueDistribution(),       // 本周截止 / 7 天内 / 逾期
    val pressureScore: Int? = null,
    val pressureLevel: String = "",              // 轻松 / 适中 / 偏高 / 很高
    val explanation: String = "",                // 压力指数原因短语
)
```

- 任务数据经 E 读接口 `snapshot()`／`snapshots`／`getTask(id)`／`getCourse(id)` 获取；任务按 `dueAt` 升序、空值最前（E 已实现）。
- 课程侧四个数字（`todayLessonCount`／`todayPeriodCount`／`weekCourseCount`／`weekEntryCount`）由 B 的 CourseService 提供，F 直接消费、不在 `StatisticsUi` 重算；同步状态与最后成功时间由 E 提供，F 只消费、不重算。
