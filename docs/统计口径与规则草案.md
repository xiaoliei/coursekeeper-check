## 一、首页与看板共用统计口径

首页摘要与数据看板使用同一套口径，任何修改必须同步两处。

| 指标 | 口径（草案） | 依赖 | 空值／边界 |
|---|---|---|---|
| 今日课程 `todayLessonCount` | 今天有效的排课条目数；同一课程不同上课时段分别计数 | B 的课程与周次计算 | 无排课显示 0 |
| 本周课程 `weekCourseCount` | 本周有有效排课的不同课程数量（与“今日排课条目数”区别开） | B | 无课程显示 0 |
| 今日截止 `dueTodayCount` | 截止日期为今天的任务，**包含已完成** | D | 0 |
| 今日完成 `completedTodayCount` | 当前为完成状态且 `completedAt` 在今天；取消完成后移除 | D | 0 |
| 本周进度 `weekTaskCount` / `weekCompletedCount` / `completionRate` | 分母：截止日期在本周一（含）至周日（含）的任务；分子：其中当前已完成的任务 | D（任务数据） | 分母为 0 时显示“暂无数据”，不显示 0% |
| 压力指数 `pressureScore` / `pressureLevel` / `explanation` | 公式见第二节 | F，日期数据来自 B、D | 数据不足时显示“暂无数据” |
| 同步状态 | idle／syncing／offline／expired／partial／error；各模块结果独立 | E | 失败不能用空结果覆盖 |

多页面一致性：用同一组固定记录核对首页、课表、任务页和看板；新增、完成、删除、同步更新后统计结果必须保持一致（沿用 A 工程已有的样例测试思路）。

## 二、压力指数草案

> 因素、权重、等级均为草案，第 1 周确认后再实现。

候选因素与默认权重：

| 因素 | 默认权重 | 计算建议（草案） |
|---|---|---|
| 任务密度 | 40% | 本周截止任务数 ÷ 本周剩余可用天数（无任务时为 0） |
| 课程负荷 | 30% | 今日有效排课条目数归一化（≥ 8 节记满分） |
| 临近截止 | 20% | 48 小时内未完成的任务数归一化（≥ 3 记满分） |
| 逾期任务 | 10% | 已过期未完成任务数归一化（≥ 2 记满分） |

等级：0–29 轻松；30–59 适中；60–79 偏高；80–100 很高（与演示“40·适中”一致）。`explanation` 须给出该分数的原因短语（如“本周任务较集中”），不能只给数字。

## 三、8 条规则清单与文案模板（草案）

> 触发条件与阈值待确认；规则可离线运行、相同输入得到相同结果，不调用模型。

| # | 规则 | 触发条件（草案） | 文案模板 |
|---|---|---|---|
| 1 | 今日截止提醒 | 存在今天截止的未完成任务 | “今天有 N 项任务截止，记得完成” |
| 2 | 24 小时临期 | 存在 24 小时内截止的未完成任务 | “学习报告将于今天 23:59 截止” |
| 3 | 任务集中 | 未来 48 小时内截止任务 ≥ 3 | “未来两天有 N 项任务，建议按截止时间排序” |
| 4 | 课程负荷 | 今日排课 ≥ 6 节 | “今天有 N 节课，注意安排休息” |
| 5 | 逾期提醒 | 存在已过期未完成的任务 | “有 N 项任务已逾期，可补录或调整” |
| 6 | 进度滞后 | 本周过半且完成率 < 50% | “本周已过半，完成率 N%，有些紧张” |
| 7 | 空数据引导 | 无课程且无任务 | “暂无课程和任务，可连接学校或手动添加” |
| 8 | 连续低完成 | 近 3 天每天完成数均为 0 且存在截止任务 | “连续几天没有完成记录，需要调整安排吗？” |

## 四、StatisticsService 接口草案（W2 实现）

```kotlin
// 首页与看板共用；数据来自 B（课程）、D（任务）、E（Repository/同步状态）
data class StatisticsUi(
    val weekTaskCount: Int = 0,
    val weekCompletedCount: Int = 0,
    val completionRate: Float? = null,          // 无任务为 null，UI 显示“暂无数据”
    val typeDistribution: List<TypeSlice> = emptyList(),   // 本周任务按类型分布
    val dueDist: DueDistribution = DueDistribution(),       // 本周截止 / 7 天内 / 逾期
    val pressureScore: Int? = null,
    val pressureLevel: String = "",              // 轻松 / 适中 / 偏高 / 很高
    val explanation: String = "",                // 压力指数原因短语
)
```

同步状态与最后成功时间由 E 提供，F 只消费、不重算。
